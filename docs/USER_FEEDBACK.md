# User Feedback Summary

The existing feedback round identified 3 recurring product issues:

| Feedback Theme | Product Response |
|---|---|
| Dashboard felt slow | Contract reads use a short-lived snapshot cache and deduplicate in-flight requests. |
| Freighter was not always detected | Wallet detection retries, requests access explicitly, watches account changes, and validates Testnet. |
| Connection failures were unclear | The connect control now displays actionable errors and a retry path. |

The live app links to the public feedback form from the footer and onboarding flow.
